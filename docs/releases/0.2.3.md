# NIGHTFALL 0.2.3 — Context Safety, Snapshots, and UI Refresh

## Release notes

NIGHTFALL 0.2.3 adds safer long-running sessions, recoverable file edits, and a refreshed chat experience.

### Added

- Automatic context compaction with an 80% default threshold.
- Configurable model context window and safety-buffer-only compaction.
- Optional pruning of older tool outputs during compaction.
- File snapshots before edits with a **Restore Last Snapshot** command.
- shadcn-inspired dark theme styling.
- Persisted light-mode setting and an in-panel light/dark toggle.

### Changed

- Assistant responses display as normal plain text instead of Markdown-styled output.
- Snapshot files are kept under `.nightfall/snapshots` and excluded from workspace search/list results.

### Verification

- 7 automated tests passing.
- TypeScript compilation passing.
